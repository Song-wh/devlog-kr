# devlog-kr

유튜브 개발 일지 채널 **[버그로그](https://www.youtube.com/@buglog_kr)**에서 만드는 프로그램을 모아 두는 저장소입니다. 프로그램마다 폴더 하나를 씁니다.

만드는 과정과 그 과정에서 나온 버그를 찾고 고치는 이야기를 영상으로 올립니다.

| 프로젝트 | 설명 | 상태 |
|---|---|---|
| [cpu-bench](cpu-bench/) | 점수만 보여 주지 않고, 내 PC가 제 성능을 내는지와 그 이유까지 알려 주는 Windows용 진단형 CPU 벤치마크 | 개발 중 |

상태 표시: **개발 중** / **운영 중** / **유지보수만** (버그 수정만) / **보관** (더 이상 고치지 않음)

## 불편한 점이나 기능 요청

[Issues](../../issues)에 남겨 주세요. 프로그램 이름을 제목 앞에 붙여 주시면 빨리 확인할 수 있습니다. 예: `[cpu-bench] 실행하면 바로 꺼져요`
